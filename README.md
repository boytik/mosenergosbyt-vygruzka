# Выгрузка документов из личного кабинета Мосэнергосбыта одной кнопкой

Для бухгалтерий, у которых в [личном кабинете Мосэнергосбыта для юрлиц](https://lkkjr.mosenergosbyt.ru)
много договоров. Вместо того чтобы скачивать документы по каждому договору
отдельно, вы выбираете месяц и нажимаете одну кнопку.

## Что вы получите

Через несколько минут в «Загрузках» появится один архив, а в нём:

- **папка на каждый договор** — по номеру или по вашей таблице договоров;
- **все документы за месяц**: акты, счета-фактуры, ведомости, счета на оплату —
  с именами без пробелов, с типом и номером документа, так что 1С распознаёт
  их сама;
- **`_перечень.csv`** — список всех документов и что с каждым случилось;
- **`_ОШИБКИ.txt`** — появляется, только если что-то не так: какой документ
  кабинет не отдал, какого договора нет в таблице.

```
244_ООО_Ромашка_50150000000001/
    50150000000001_Акт_приема-передачи_№Э-15-000001_31.08.2026.pdf
    50150000000001_Счет-фактура_№Э-15-000001_31.08.2026.pdf
    50150000000001_Счет_на_оплату_№50100000000001_11.09.2026.pdf
_перечень.csv
```

## Это безопасно?

Да. Кнопка работает в вашем браузере, пока вы сами вошли в кабинет.
Пароль ей не нужен — она его не знает и не хранит. Документы никуда,
кроме вашего компьютера, не уходят.

## Установка — 10 минут, один раз

### Шаг 1. Поставьте Tampermonkey

Tampermonkey — бесплатное дополнение для Google Chrome. Через него в кабинете
появится кнопка.

Откройте [Tampermonkey в магазине Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
и нажмите «Установить».

### Шаг 2. Включите переключатель — это важно!

Без него ничего не заработает, и Chrome ничего об этом не скажет.

1. В адресной строке наберите `chrome://extensions` и нажмите Enter.
2. Найдите Tampermonkey и нажмите «Подробнее».
3. Включите **«Разрешить пользовательские скрипты»**.

### Шаг 3. Добавьте кнопку

Откройте ссылку:
**[установить кнопку выгрузки](https://github.com/boytik/mosenergosbyt-vygruzka/raw/main/mes_lkkjr_vygruzka.user.js)**

Tampermonkey сам покажет окно — нажмите **«Установить»**. Обновления будут
приходить сами.

## Как выгружать

1. Войдите в личный кабинет как обычно.
2. Откройте «История» → «Документы».
3. Внизу справа появится панель «Выгрузка документов по всем договорам».
4. Выберите месяц «с» и «по».
5. По желанию — выберите таблицу договоров в Excel, чтобы папки назывались
   по ней (см. ниже). Таблица запомнится.
6. Нажмите **«Скачать всё в ZIP»**.

Пока идёт выгрузка, в панели видно, какой договор сейчас обрабатывается.
Архив распаковывайте двойным щелчком. Если внутри есть `_ОШИБКИ.txt` —
прочитайте его до загрузки в 1С.

### Таблица для имён папок (необязательно)

Обычный файл Excel (.xlsx), первый лист:

| Колонка 1 | Колонка 2 | Колонка 3 | Колонка 4 | Колонка 5 |
|---|---|---|---|---|
| номер договора в кабинете МЭС | что угодно | ваш короткий номер | что угодно | наименование |
| 50150000000001 | | 244 | | ООО «Ромашка» |

Папка получится `244_ООО_Ромашка_50150000000001`. Кавычки убираются,
пробелы и тире становятся подчёркиваниями. Если один номер договора стоит
в таблице на нескольких строках, номера и названия склеиваются, а папка
попадает в `_ОШИБКИ.txt` с пометкой «проверьте».

## Если что-то пошло не так

**Панель не появилась.** Почти всегда — не включён переключатель из шага 2.
Включите и обновите страницу кабинета.

**Кабинет попросил войти заново посреди выгрузки.** Кабинет выходит
из аккаунта, если долго «не видит» вас. Всё уже скачанное сохранится
в архив, а номер договора, с которого продолжить, подставится в панель сам.
Войдите снова и нажмите кнопку — уже скачанное повторно не качается.
Получится два архива: распакуйте их в одну папку.

**В архиве только ведомости, без актов и счетов.** Скорее всего,
Мосэнергосбыт ещё не выложил документы за этот месяц. Повторите позже.

**Папка названа просто номером.** Этого договора нет в вашей таблице.
Допишите его и выберите таблицу заново.

**В архиве кракозябры вместо русских имён.** Распаковывайте двойным
щелчком в Finder или Проводнике, а не консольным `unzip`.

## Если кабинет изменится

Кнопка повторяет то, что делает сам кабинет. Если Мосэнергосбыт его
переделает, кнопка может перестать работать — тогда панель покажет ошибку.
Напишите в [Issues](https://github.com/boytik/mosenergosbyt-vygruzka/issues).
